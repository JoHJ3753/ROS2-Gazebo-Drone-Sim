# 드론 명령 데이터셋 v0.5

한국어 드론 명령을 프로젝트 JSON 명령 스키마에 맞게 변환하기 위한 데이터셋이다.
각 JSONL 줄에는 사용자 입력(`user`)과 기대 출력(`assistant`)이 들어 있다.

| 파일 | 건수 | 용도 |
| --- | ---: | --- |
| `train.jsonl` | 454 | 모델 학습 |
| `validation.jsonl` | 20 | 학습 중 검증 |
| `test.jsonl` | 30 | 학습 후 평가 |

## v0.4에서 변경한 내용

- 학습 데이터 430건을 바탕으로 새 문장 24건을 추가했다.
- 기존 학습 문장 중 어색한 표현 4건(`뒤으로`, `위으로`)을 고쳤다. 해당 문장의 정답은 바꾸지 않았다.
- 검증 20건과 시험 30건은 새 문장으로 구성했다.

추가 학습 문장은 예약·반복 실행, 지원하지 않는 조건부 동작,
필수 거리·각도·단위가 빠진 요청을 중심으로 만들었다.

## 사용 기준

- `train.jsonl`만 모델 가중치 학습에 사용한다.
- `validation.jsonl`은 학습 중 점검에 사용한다.
- `test.jsonl`은 모델과 설정을 정한 뒤 평가한다. 시험 결과를 보고 데이터나 설정을 수정했다면, 같은 시험 점수를 독립적인 최종 성능으로 해석하지 않는다.
- v0.4와 v0.5의 시험 문장이 다르므로 두 버전의 점수를 직접 비교하지 않는다.
- 학습 전에는 새 문장의 의미와 정답이 맞는지 사람이 검토한다.

# 드론 명령 데이터셋 v0.6

한국어 드론 명령을 프로젝트 JSON 명령 스키마에 맞게 변환하기 위한
강건성 강화 데이터셋이다. v0.5 학습 데이터 전체를 유지하면서 실제 사용자가
입력할 법한 사투리, 맞춤법 오류, 오타, 띄어쓰기 오류, 구어체 표현을 추가했다.

| 파일 | 건수 | 용도 |
| --- | ---: | --- |
| `train.jsonl` | 804 | 모델 학습 |
| `validation.jsonl` | 20 | 학습 중 정상 문장 검증 |
| `test.jsonl` | 30 | 기존 정상 문장 성능 비교 |
| `test_robustness.jsonl` | 100 | 오타·사투리·구어체 강건성 평가 |

## v0.5에서 변경한 내용

- v0.5 학습 데이터 454건을 그대로 유지했다.
- 기초 강건성 학습 데이터 250건을 추가했다.
  - `accepted`: 170건
  - `clarification_required`: 45건
  - `unsupported`: 20건
  - `invalid`: 15건
- 명령 및 파라미터 적중률을 위한 `accepted` 대조·보강 사례 100건을
  추가해 전체 신규 학습 데이터는 350건이다.
- 자주 쓰는 구어체와 지역 표현, 띄어쓰기 오류, 발음대로 쓴 표현,
  오타가 포함된 명령을 보강했다.
- 상대적으로 사례가 적었던 `land`, `hover`, `arm`, `disarm`, `cancel`,
  `recall`, `return_home` 명령도 함께 보강했다.
- 선택 파라미터 누락을 줄이기 위해 속도, 회전 속도, 촬영 간격,
  호버링 시간 사례 30건을 추가했다. 특히 기존 학습 데이터에 없었던
  `move_clock_direction.speed_mps` 사례 15건을 포함했다.
- `arm`/`takeoff`, `land`/하강, `hover`/`emergency_stop`,
  `return_home`/`recall`처럼 혼동하기 쉬운 명령의 대조 사례를 추가했다.
- 숫자, 소수, 단위, 어순이 달라져도 같은 파라미터를 추출하도록
  다양한 파라미터 표현 사례를 추가했다.
- 오타가 있더라도 필수 인자가 빠졌다면 값을 추측하지 않고
  `clarification_required`로 응답하도록 구성했다.

## 평가 기준

- `test.jsonl`은 v0.5와 동일하다. 정상 문장 성능을 이전 버전과 비교할 때
  사용한다.
- `test_robustness.jsonl`은 학습에 포함되지 않은 100건으로 구성했다.
  오타·사투리·구어체에 대한 성능은 이 파일로 별도 평가한다.
- 기존 학습 실행 코드는 이 파일이 존재하면 파인튜닝 전후 강건성 평가를
  자동 실행한다. 결과는 `metrics.json`, `comparison_report.txt`,
  `training_log.txt`와 별도의 강건성 예측·실패 JSONL 파일에 저장한다.
- 두 시험 결과를 하나의 정확도로 합치지 않는다. 어려운 강건성 시험을
  추가하면 전체 점수가 낮아져 모델이 퇴보한 것처럼 보일 수 있다.
- 시험 결과를 확인한 뒤 데이터나 설정을 수정했다면 해당 시험 점수는
  독립적인 최종 성능으로 해석하지 않는다.

## 학습 권장 사항

- 누적 데이터셋을 기존 어댑터에 이어 학습하므로 우선 낮은 학습률과
  1 epoch로 실행한다.
- 정상 문장 `test.jsonl` 정확도가 크게 하락하면 학습률이나 epoch를 낮춘다.
- 최종 모델은 정상 문장 정확도와 강건성 정확도를 모두 기록해 선정한다.
